# ✈️ Smart Trip Calculator

### AI-Based Travel Budget Planner

## About
Smart Trip Calculator helps users plan
their trips and calculate travel expenses.

## Features
- Enter starting location
- Enter destination
- Select travel mode
- Choose hotel type
- Calculate total trip budget
- Calculate per-person cost

## Technologies
- Python
- Streamlit
- GitHub

## How to Run
1. Install Python
2. Install requirements:
   pip install -r requirements.txt
3. Run:
   streamlit run app.py
